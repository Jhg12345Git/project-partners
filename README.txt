PROJECT FUNDING STRAWMAN WEBSITE

Open index.html in any modern browser.

This prototype includes:
- Home/hero introduction
- Featured project
- Large projects, community projects, and small tasks
- Funding required, committed, remaining, and progress bars
- Category filters
- Clickable project-detail modal
- Completed-project section
- Responsive mobile layout

The colored image areas are placeholders. They are intentionally easy to replace with actual project photographs.
